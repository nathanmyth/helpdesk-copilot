# Software Requests

_Fictional sample document for Northwind Labs. Last updated: 2026-10-01._

## Installing approved software
Most approved applications (browsers, Zoom, Slack, VS Code, Python) can be installed without a ticket from the Software Center app on your company laptop. Open Software Center, search for the application, and click Install.

## Requesting new software
Software that is not in the Software Center needs approval. Submit a Software Request form in the IT Service Portal with the software name, business reason, and your manager's name. Security reviews new software within 5 business days. Software that processes customer data also needs a privacy review.

## Admin rights
Employees do not have local administrator rights on company laptops. Do not attempt to bypass this restriction. Developers who need elevated rights can request a time-limited admin session through the IT Service Portal; sessions last 60 minutes.

## Browser extensions
Only extensions on the approved list can be installed in Chrome and Edge. Unapproved extensions are removed automatically.
